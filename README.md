# Portfolio Hugo Barral — version Wix Headless légère

Cette version ne contient **aucun fichier audio ou vidéo**, afin de rester légère pour l'import Wix Headless.

## À connecter après l'import
- Vidéos : liens / embeds Vimeo.
- Audios : liens / embeds depuis l'hébergeur audio choisi.
- Articles : pages HTML déjà incluses.

Les cartes radio contiennent des boutons prêts à recevoir les liens audio.
Les cartes TV contiennent des emplacements prêts pour les vidéos Vimeo.

## À modifier
Remplacer `contact@hugobarral.fr` par ton adresse email réelle.
